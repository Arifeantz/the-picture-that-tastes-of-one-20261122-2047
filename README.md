A pure-stdlib Python program that paints one delicious picture: a big golden honeycomb slab, glossy with fresh honey, a wooden honey dipper resting across it, a slow drip falling into a glistening pool of honey on a warm wooden board. It draws every pixel procedurally — layered gradients, specular highlights, honeycomb cells, drizzle ribbons and soft shadows — and writes a 1024x1024 PNG with its own hand-rolled PNG encoder (zlib + struct, no third-party packages, no network).

## Run it

```sh
python3 main.py
```
